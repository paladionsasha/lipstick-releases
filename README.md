# Lipstick

Расшифровка русской речи из видео и аудио — прямо на компьютере, без отправки записей в интернет.
Windows 10+ и macOS (Apple Silicon).

## Скачать

Последняя версия — в разделе **[Releases → Latest](../../releases/latest)**:

- **Windows:** `Lipstick-setup-<версия>.exe`
- **macOS (Apple Silicon):** `Lipstick-<версия>-macos-arm64.dmg`

Дальше программа обновляется сама: при запуске проверяет этот репозиторий и предлагает
поставить новую версию.

## Что умеет

- Перетаскиваешь видео или аудио любого формата — получаешь текст на русском, с пунктуацией и цифрами.
- Работает локально, без интернета: записи никуда не отправляются. Интернет нужен один раз —
  скачать модель распознавания (~240 МБ).
- **Разделение по говорящим:** указываешь, сколько людей в записи, — реплики подписываются.
  Спикерам можно дать имена («Спикер 1» → «Ирина»).
- Текст сохраняется в `.txt` рядом с исходным файлом.
- **История расшифровок:** открыть старый результат, переименовать, удалить.
- Прогресс, отмена, время обработки.
- **«✉ отзыв»** — написать автору прямо из программы, по желанию с логом.
- Самообновление.

## При первом запуске

- **Windows** может показать «Windows защитила ваш компьютер» — у программы пока нет платной
  подписи. «Подробнее» → «Выполнить в любом случае».
- **Mac:** если программа не открылась — Настройки → Конфиденциальность и безопасность →
  «Всё равно открыть».

## Что планируется

- Прослушать короткий фрагмент голоса каждого спикера, чтобы точно подписать имена.
- Вручную поправить, кому принадлежит реплика, если программа ошиблась.
- Обработка нескольких файлов подряд, очередью.
- Просмотр и правка текста прямо в программе.
- Свой словарь: исправил имя или термин один раз — дальше пишется правильно.
- Запись звука с компьютера (созвоны, вебинары) прямо из программы.
- Шумоподавление перед расшифровкой.
- Позже: субтитры (SRT), краткий пересказ и поиск по расшифровкам.

Что важнее — пишите через «✉ отзыв» в программе: от этого зависит порядок.

## FFmpeg

Mac-версия при первом запуске скачивает FFmpeg из релиза `ffmpeg-<версия>`.
Это урезанная LGPL-сборка из официальных исходников [ffmpeg.org](https://ffmpeg.org/),
без изменений в коде FFmpeg. Лицензия, ссылка на исходники и параметры сборки
приложены к релизу.
