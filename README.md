# Lipstick — релизы

Здесь лежат готовые сборки Lipstick (расшифровка русской речи из видео и аудио).
Программа сама проверяет этот репозиторий при запуске и предлагает обновиться.

- **macOS (Apple Silicon):** `Lipstick-<версия>-macos-arm64.dmg` в разделе [Releases](../../releases).
- **Windows:** `Lipstick-setup-<версия>.exe` там же.

## FFmpeg

Mac-версия при первом запуске скачивает FFmpeg из релиза `ffmpeg-<версия>`.
Это урезанная LGPL-сборка из официальных исходников [ffmpeg.org](https://ffmpeg.org/),
без изменений в коде FFmpeg. Лицензия, ссылка на исходники и параметры сборки
приложены к релизу.
